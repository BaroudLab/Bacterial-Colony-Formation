# Bacterial-Colony-Formation

This repository contains tables and jupyter notebooks needed to reproduce analysis and generate all plots from main and supplementary figures from the article "Single-bacteria probability of colony formation under antibiotic stress" by Maikranz et al. Of particular interest might be "InferenceValidation.ipynb" notebook, which allows to simulate the performance of the inference techniques for various parameters, which includes Poisson and negative binomial distributon of initial cell number.
